# Sentinel IDS

The GitHub-ready runnable project is in [sentinel-ids-release](sentinel-ids-release/README.md).

That folder contains the refined dashboard, FastAPI inference API, small approved Random Forest model bundle, training utility, operational documentation, dependency files, and an easy Windows startup script. It deliberately excludes CICIDS training data, local captures, alerts, virtual environments, Node modules, and generated builds.

Follow the two commands in the [release README](sentinel-ids-release/README.md#quick-start-on-windows) to run it locally.
